Multi-Device Google Drive & Cloud Sync

Synchronize world saves, passkeys, and host locks across all members' PCs

How to Host Across Multiple PCs with Google Drive:
  1. Install Google Drive for Desktop on each member's PC.
  2. Create a folder (e.g. MineRelay-Shared) in your Google Drive, right-click it → Share with your friends (Editor access), and have each friend click "Add shortcut to My Drive".
  3. On each PC, click Browse... above and select that shared folder (e.g. G:\My Drive\MineRelay-Shared). Passkeys, world saves, and the active host lock will sync automatically!
